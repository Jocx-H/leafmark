# 实现说明

本文记录设计文档未完全确定、在实现阶段拍板的细节。设计基线见 [design.md](design.md)。

## 1. 什么文件算「尝试使用规范命名」

设计文档只规定「看起来采用了规范但编号、标签或标题不合法」属于 `invalid`，没有定义判定阈值。为避免把 `2个想法.md`、`2024年终总结.md` 这类普通文件误判为异常，解析器采用：

- 以至少 5 位数字开头并紧跟 `_`，或
- 以至少 6 位数字开头，

才视为编号尝试。其余文件一律为 `unmanaged`。

`01020_标题.md`（5 位）因此是 `invalid`，而 `2024年终总结.md` 是 `unmanaged`。

## 2. 标签显示形式

设计文档要求「保留第一次扫描到或用户选定的写法」，但扫描顺序依赖文件系统，跨平台可能不同，会破坏验收标准中「两端解析一致」的要求。

实现改为确定性规则：在同一个标签身份（NFC + 小写）下，

1. 使用次数最多的拼写优先；
2. 次数相同时，取最小文档编号对应的拼写；
3. 仍相同时按字典序。

标签筛选使用身份键比较，展示使用选定的拼写。

## 3. 编号冲突的占用范围

冲突检测覆盖所有「六位数字编号」的文件，即使该文件同时存在标签或标题错误；自动分配只统计 `valid` 文档的序号。

这样不会出现「一个非法文件占着 010203，另一个合法文件又被分配到 010203」的情况。

## 4. 分类树与异常视图

- 分类树只统计 `valid` 与 `conflict`，按编号归位；
- `invalid`、`unmanaged` 只出现在独立视图；
- 分类名称缺失时显示「未配置」，不虚构名称；
- 「全部文件」包含所有状态，便于搜索。

## 5. 大小写与 Unicode 比较

不依赖操作系统：所有名称比较统一走 `NFC + toLowerCase`。这比实际文件系统更严格（例如 Linux 上区分大小写），但方向安全，且保证 Windows / macOS 行为一致。

## 6. 扩展名

扫描按配置的扩展名进行，默认不区分大小写；`010203_标题.MD` 会被视为 `valid` 并附带「重命名时规范化为 .md」的警告。任何重命名都会写回小写 `.md`。

## 7. 重命名计划

- `planId` 由主进程生成，10 分钟过期，一次性使用；
- 提交时重新校验源文件大小与修改时间、目标占用、大小写冲突、编号唯一性；
- 仅大小写变化通过唯一临时文件名中转，避免大小写不敏感文件系统合并条目；
- 提交失败时保留源文件，并要求重新生成预览。

## 8. 新建文档

新建文件固定创建在工作区根目录，只写入 0 字节内容，不生成 Front Matter 或模板。

## 9. 配置缺失与损坏

- 缺失：使用内存默认配置运行，界面显示可关闭的提示条，可一键创建 `.leafmark.json`；
- 损坏：显示具体 JSON 位置或字段路径，进入只读状态，阻止重命名与新建，可恢复默认配置；
- 写入保留未知字段，便于未来版本平滑升级。

## 10. 文件监听

使用 Node 原生 `fs.watch({ recursive: true })`，400 ms 防抖；事件没有文件名时退化为全量重扫。软件自身的重命名直接更新内存视图，监听事件触发的重扫在数据未变化时不会递增快照版本，避免界面闪烁。

## 11. 性能实测

在 Apple M1 / macOS 13 上，5000 个 Markdown 文件的首次扫描约 80 ms（目标 2 s），内存快照序列化后约 3 MB。MVP 采用全量快照推送，1 万文件以上可考虑改为增量推送。

## 12. 可配置扩展名

`scan.extensions` 决定扫描哪些扩展名。解析器接受配置中的扩展名，但重命名时始终写回小写 `.md`，因此 `.markdown` 等扩展名的文档会显示规范化警告。这样配置项不会形同虚设，命名规范也保持唯一。

## 13. 标题开头的方括号

未纳入管理的文件如果本身叫 `[GPU]使用CUDAGraph.md`，标题会被初始化为 `[GPU]使用CUDAGraph`。为了能直接纳入管理，编辑器会：

- 初始化草稿时提取开头连续的 `[标签]` 组，放进标签区；
- 在标题输入框里输入或粘贴 `[GPU]使用…` 时，输入到 `]` 的瞬间自动把 `[GPU]` 转为标签；
- 只提取合法标签；遇到 `[a/b]`、未闭合的 `[GPU` 等保持原样并报错。

标题一律不允许以 `[` 开头（即使已经有标签）。否则生成的 `AABBCC_[已有标签]_[新标题].md` 会在下次扫描时被解析成额外的标签，导致元数据静默漂移。

## 14. 界面与交互

- 编辑器实时调用主进程生成预览，但提交按钮只依赖主进程返回的错误列表；
- 标签顺序通过左右箭头调整，标签块按原顺序写回文件名；
- 重命名确认弹窗可通过配置关闭；
- 链接风险提示默认开启，不声称已经修复链接。
